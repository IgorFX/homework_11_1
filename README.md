# Виджет банковских операций

## Описание:

### Модуль `processing.py`

Виджет использует две функции `filter_by_state`, которая 
принимает список словарей и опционально значение для ключа 
`state` (по умолчанию `EXECUTED`) `CANCELED`.

Функция `sort_by_date` принимает список словарей и необязательный 
параметр, задающий порядок сортировки (`descending=True` по умолчанию — убывание).
возвращаeт новый список, отсортированный по дате.

### Модуль `widget.py`

Функция `mask_account_card` возвращает название карты и маскиолваный номер 
карты(счета) в формате `str` название карты и маскированный номер карты
ф формате XXXX XX** **** XXXX, либо Счет **XXXX.

Функция `get_date` принимает стоку с датой и временем, возвращает дату 
в формате ДД.ММ.ГГ

### Модуль `masks.py`

Функция `get_mask_card_number` принимает номер карты в формате int 
в виде XXXXXXXXXXXXXXXX и возвращает в формате str виде XXXX XX** **** XXXX

Функция `get_mask_account` принимает номер счета в int и возвращает в формате str в виде **XXXX
